#Mortgage Intelligence Platform

Capstone project repository

##git workflow

##branches

main = production ready
develop = integration branch
###feature branch naming

feature/

Example: feature/M1-project-structure

##commit convention

type(scope): summary

Examples: docs(requirements): add personas and scope feat(api): create borrower endpoint fix(auth): resolve login validation

##pull request workflow

create feature branch from develop
commit changes
open PR into develop
Obtain atleast one peer review
merge after approval
No direct commits to develop once team review policy is active.
